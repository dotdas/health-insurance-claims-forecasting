# Health Insurance Claims Forecasting

Academic group project analysing health-insurance claims data to forecast claim frequency, claim severity, and total claim expenditure.

## Contents

- `health_insurance_claims_forecasting.ipynb` — exploratory analysis, feature engineering, time-based validation, and monthly forecasting workflow.

## Notes

- This repository intentionally contains source material only. The original datasets, competition guide, submission file, exported reports, and any sensitive claim-level data are excluded.
- The notebook is preserved as an academic project record and is not presented as production insurance or financial advice.
- Contributions and results should be understood in the context of the original group project.

## Requirements

Open the notebook in Jupyter and install the libraries imported in it. To reproduce the work, place the original authorised datasets in the expected local paths; they are not distributed in this repository.
